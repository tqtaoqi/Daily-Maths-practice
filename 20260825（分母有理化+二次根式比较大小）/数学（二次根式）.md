# 七年级数学竞赛题精选

## 题目一：分母有理化与整体代入求值

【背景】
分母有理化是化简二次根式的重要方法，通过将分母中的根号去掉，可以将复杂的根式化为更简洁的形式。

例如：$\dfrac{1}{\sqrt{2}+1} = \dfrac{\sqrt{2}-1}{(\sqrt{2}+1)(\sqrt{2}-1)} = \dfrac{\sqrt{2}-1}{2-1} = \sqrt{2}-1$。

【问题】
已知 $x = \dfrac{1}{2+\sqrt{3}}$，$y = \dfrac{1}{2-\sqrt{3}}$，

（1）求 $x + y$ 和 $xy$ 的值；

（2）求 $x^2 + y^2 - 5xy$ 的值。
