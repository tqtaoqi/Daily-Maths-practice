# 七年级数学竞赛题精选

## 题目一：平方根与立方根的综合逆推

【背景】
若一个正数 $x$ 的平方根是 $\pm m$，则 $x = m^2$；若一个数 $y$ 的立方根是 $n$，则 $y = n^3$。由平方根、立方根的定义可以"逆向"求出字母的值，再进一步求新的代数式的平方根。

例如：若 $x+1$ 的平方根是 $\pm 2$，则 $x+1 = 2^2 = 4$，$\therefore x = 3$。

【问题】
已知 $3a+1$ 的平方根是 $\pm 4$，$2a-b+4$ 的立方根是 $-2$，求 $a+2b$ 的平方根。

## 题目二：数轴与二次根式的化简

【背景】
$\sqrt{a^2} = |a|$，化简结果取决于 $a$ 的符号，因此需要结合数轴上点的位置先判断各个式子的正负，再去掉绝对值符号。

例如：若 $a > 0$，则 $\sqrt{a^2} = a$；若 $a < 0$，则 $\sqrt{a^2} = -a$。

【问题】
实数 $a$、$b$ 在数轴上对应的点位于原点两侧，且 $a$ 在原点左侧、$b$ 在原点右侧，$|a| > |b|$。

化简：$\sqrt{a^2} - |a+b| + \sqrt{(a-b)^2}$。
